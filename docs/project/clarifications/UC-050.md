# UC-050 Rate seed

## What can be rated
- Only seeds whose group has presented are rated.
- Ratings can change until the participant submits them (`UC-052.md`).

## Rating notes
- While rating, the participant can write an optional note per seed, to remember why they liked it.
- Private: only their author sees them, not staff or evaluators.
- Temporary: kept in server memory like the ratings (`UC-052.md`), never stored in the database.
- New step, pending SRS change (D-062).

Decisions: D-049, D-062.
