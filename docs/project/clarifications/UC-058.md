# UC-058 Create exploring groups

## Groups and seeds
- At least one group.
- Each group works on a different seed. Seeds without a group are allowed, but not preferred.

## Starting group work
- `GROUP_WORK` can't start while a group has no voice (BRU-032), or while an assisting participant has no group
  (pending SRS change, D-049).
- Naming a second voice in a group replaces the first.

Decisions: D-049.
