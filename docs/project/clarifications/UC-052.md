# UC-052 Submit seed ratings

## When a participant can submit
- After every group has presented, with every presented seed rated.
- Not every participant has to submit before `TEAM_CREATION`.

## Who sees ratings
- Staff (facilitators, designers, administrators) and evaluators see every rating.
- Each participant sees only their own.

## Where ratings are kept
- In server memory, from rating until team creation, which is the only step that uses them. They aren't stored in
  the database. Rating notes (`UC-050.md`) are kept the same way.
- A server restart before team creation loses them, and participants rate again (accepted risk).

Decisions: D-049, D-062.
