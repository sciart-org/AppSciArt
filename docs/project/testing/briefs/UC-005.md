## Vocabulary
- Join yourself = `POST /hackathons/{hackathonId}/participants/me`. Enrol a given user =
  `POST /hackathons/{hackathonId}/participants/{userId}` (`userId` = user profile id). Body: `roles` (any of
  `ARTIST`, `TECHNOLOGIST`, `SCIENTIST`, `OTHER`) and `interests` (the reason for joining).
- Read back: `GET /hackathons` as the enrolled user; the hackathon's item has `isEnrolled: true` (UC-004).
- Announced (open, upcoming) = state `OPEN`.
- Guest = not logged in; participant = authenticated, no staff role; staff = facilitator, designer, administrator.

## Test cases
Enrolling yourself
- **B1** A participant joins an announced hackathon through `participants/me` → `201`, and the hackathon is marked
  enrolled for them.
- **B2** A participant enrols themselves through their own user id → `201`, marked enrolled for them.

Enrolling someone else
- **B3** A participant enrolling another participant → `403`, and the hackathon is not marked enrolled for the
  other participant.
- **B4** A guest enrolling a participant → `401`, not marked enrolled for that participant.
- **B5** A facilitator enrols a participant → `201`, marked enrolled for that participant (user's decision
  2026-11-10).
