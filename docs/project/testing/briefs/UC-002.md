# UC-002 View list of ASTER+S editions → `backend/tests/acceptance/editionsList.test.js`

## Requirement
- UC-002 (`srs-export.txt` ~line 829): "In the corresponding section, the system will show a list of all published
  ASTER+S editions, including incoming, ongoing, and past editions. Exception: In case no publicly visible edition
  exists, the system will show an empty list."
- IRQ-005 Edition information (~line 2381): name, year, logo, status, short description ("shown in the system as
  part of the preview of the edition").
- BRU-004 Edition announcement (~line 2622).

## Clarifications
- `docs/project/clarifications/UC-002.md`: all sections.
- `docs/project/clarifications/general.md`: "Actors", "HTTP meaning", "Edition states".

## Vocabulary
Not announced = `PLANNED`; announced = `ACTIVE`; closed = `CLOSED`; published = `PUBLISHED`. Guest = no token;
participant = authenticated, no staff role; staff = facilitator, designer, administrator.

## Test cases
Visibility
- **B1** Guest gets an empty list when no edition exists.
- **B2** Guest gets an empty list when only not-announced editions exist.
- **B3** Guest sees announced, closed and published editions, each with its `state`.
- **B4** Guest never sees not-announced editions.
- **B5** Participant sees exactly the same editions as a guest.
- **B6** Each staff role also sees not-announced editions, without a filter.

Filter by state
- **B7** Guest asking for `?state=PLANNED` → `401`.
- **B8** Participant asking for `?state=PLANNED` → `403`.
- **B9** Each staff role asking for `?state=PLANNED` gets only not-announced editions.

Fields
- **B10** Guest items have exactly `id`, `state`, `name`, `year`, `shortDescription`, `logo`, plus optional
  `fruitLogo`; the required ones are present.
- **B11** Participant items have the same field set, with the required ones present; no `driveLink`.
- **B12** Staff items have the same set plus `driveLink`, and nothing else.
- **B13** `name`, `year` and `shortDescription` are the edition's; `logo` is a link.
- **B14** For staff, a not-announced edition without short description or logo is listed, with those fields absent
  or `null`.

## Fixture notes
- `anEdition` and its shortcuts (`aNotAnnouncedEdition`, `anAnnouncedEdition`, `aClosedEdition`,
  `aPublishedEdition`); pass `null` for a missing field and `logo: false` for no logo.
- No order is required: never assert on the order of items.
